Every link becomes

YouTube To MP3 is a small Electron desktop app: paste a link, pick a bitrate, get a finished MP3 in your downloads folder. No web upload, no account, no ads — it runs on your machine.

The pipeline

Three steps, all local.

01

Paste a link

Drop in any YouTube URL. The app fetches the video's title and metadata with ytdl-core before touching your disk.

getInfo()
02

Pull the audio

The audio-only stream downloads straight to a temporary file, with a live progress bar tracking bytes received.

audioonly
03

Encode & clean up

A bundled ffmpeg binary encodes the temp file to MP3 at your chosen bitrate, then the temp file is deleted.

fluent-ffmpeg

Run it yourself

Clone, build, start.

# clone the repo
git clone https://github.com/Vaporjawn/Youtube-to-MP3.git
cd Youtube-to-MP3

# install dependencies
yarn

# bundle the renderer with webpack
yarn build

# launch the Electron app
yarn start
